# Raw Benchmark & Validation Data (`experiments/raw-data/`)

This directory stores the raw experimental outputs collected by **Member 3 (TV3: Automation & Test Case Validation)** via `experiments/scripts/run_benchmarks.ps1` and `experiments/scripts/run_validation_tests.ps1`.

> **Note:** Raw data files are generated by running the benchmark pipeline against the actual compiled server (TV1) and load generator (TV2). Do not commit fabricated data.

## Generated Directory Layout

```text
experiments/raw-data/
├── benchmark_results.csv        # Master 3x3 benchmark table (1, 10, 50 clients x 3 runs = 9 rows)
├── cpu_metrics.csv              # Per-run Server CPU (%) & Working Set memory summary (9 rows)
├── validation_results.csv       # Summary of 4 mandatory validation test cases (TC1-TC4)
├── validation_report.json       # Detailed validation report with timestamps & assertions
├── environment_metadata.json    # Hardware, OS, JVM, and active benchmark parameters
├── runs/
│   ├── c1_run1.csv              # Individual run CSV from LoadGeneratorApp
│   ├── c1_run1.json             # Individual run JSON from LoadGeneratorApp
│   └── ... (c1_run1..3, c10_run1..3, c50_run1..3)
├── cpu/
│   ├── cpu_c1_run1.csv          # Per-second server CPU (%) & Working Set samples during measurement
│   └── ...
└── logs/
    ├── server_stdout.log / server_stderr.log
    ├── loadgen_c*_run*.out.log / .err.log
    └── val_*.out.log / .err.log
```

## CSV Schemas (UTF-8 without BOM)

### 1. `benchmark_results.csv` (TV2 `MetricsCollector` format, consumed by TV4 `analyze_data.py`)
| Column | Type | Description |
|---|---|---|
| `run_id` | int | Repetition index per client level (`1`, `2`, `3`) |
| `clients` | int | Concurrent client connections (`1`, `10`, `50`) |
| `duration_sec` | int | Measurement window duration in seconds (default `20`) |
| `payload_bytes` | int | Payload size per frame in bytes (default `1024`) |
| `total_success` | long | Total verified echo requests in measurement window |
| `total_errors` | long | Total failed/timed-out/mismatched requests |
| `throughput_req_s` | float | Throughput in requests/second |
| `avg_latency_ms` | float | Mean round-trip latency (ms) |
| `p95_latency_ms` | float | 95th percentile tail latency (ms) |
| `error_rate_percent` | float | Error percentage (`total_errors / total_requests * 100`) |

### 2. `cpu_metrics.csv` (Server CPU summary per run)
| Column | Type | Description |
|---|---|---|
| `run_id` | int | Repetition index (`1`, `2`, `3`) |
| `clients` | int | Concurrent client connections (`1`, `10`, `50`) |
| `samples` | int | Number of CPU samples collected during measurement |
| `avg_cpu_percent` | float | Mean server CPU utilization (`0..100%` across logical cores) |
| `max_cpu_percent` | float | Peak sampled server CPU utilization (`%`) |
| `min_cpu_percent` | float | Minimum sampled server CPU utilization (`%`) |
| `p95_cpu_percent` | float | 95th percentile sampled server CPU utilization (`%`) |
| `avg_working_set_mb` | float | Mean server process working set memory (`MB`) |

### 3. `validation_results.csv` (Mandatory Test Cases)
| Column | Type | Description |
|---|---|---|
| `test_id` | string | `TC1`, `TC2`, `TC3`, `TC4` |
| `test_name` | string | Human-readable test case title |
| `status` | string | `PASS` or `FAIL` |
| `duration_ms` | int | Test execution duration in milliseconds |
| `details` | string | Measured metrics and assertion summary |

## How to Run

### Dry run (inspect discovered sources and planned 3x3 matrix without executing):
```powershell
powershell -ExecutionPolicy Bypass -File experiments/scripts/run_benchmarks.ps1 -DryRun
```

### Full 3x3 benchmark + all 4 validation tests (auto-starts TV1 server & runs TV2 client):
```powershell
powershell -ExecutionPolicy Bypass -File experiments/scripts/run_benchmarks.ps1
```

### Run against an already running server:
```powershell
powershell -ExecutionPolicy Bypass -File experiments/scripts/run_benchmarks.ps1 -UseExternalServer
```

### Run only the 4 validation test cases against a running server on `127.0.0.1:8080`:
```powershell
powershell -ExecutionPolicy Bypass -File experiments/scripts/run_validation_tests.ps1
```
